# Jeff Notes: 极致学术录音助手

Jeff Notes 是一款专为学术讲座、课堂记录设计的 iOS 实时转录与总结工具。它通过"跨云算力混编"技术，将 Groq 与硅基流动的最强模型整合进一个极简的 1/3 分屏界面中。

## ✨ 核心特色

- **三模式学术引擎**：
    - **🎓 讲座模式 (Lecture)**：深度挖掘 Thesis Statement，还原完整考点地图，生成穿透式逻辑图（蓝色主题，摘要卡片默认展开）。
    - **👥 讨论模式 (Discussion)**：捕捉多方观点冲突与共识，生成地道的中英双语口语复述稿（紫色主题，摘要卡片默认折叠）。
    - **💬 闲谈模式 (FreeTalk)**：纯双语实时转写翻译，跳过 AI 总结，直接导出精炼中英对照文本。
- **跨云混编大脑**：
    - **Groq (Whisper-large-v3)**：负责极速语音转写 (STT)，告别等待。
    - **硅基流动 (Qwen 2.5-32B-Instruct)**：负责实时翻译与全篇复盘，导师级水准。
    - **硅基流动 (Qwen 2.5-72B-Instruct)**：负责 60 秒滑动窗口语义摘要与翻译兜底，精准捕捉考点。
- **Session Isolation 架构**：
    - 录音与处理完全解耦，停止当前录音可立即开始下一场，AI 在后台静默完成总结。
- **双轨 AI 管线 (Dual-Track Pipeline)**：
    - **快车道**：每 5-8 秒切片即时 STT，英文原文几乎零延迟呈现。
    - **慢车道**：每段英文立即翻译（batchSize=1），中文翻译紧随其后，主服务故障自动切换到兜底模型。
- **音频拼接 (Overlap-Stitch)**：
    - 25600 字节尾部重叠拼接，彻底杜绝切片边界断词。
- **崩溃恢复 (Shadow Cache)**：
    - 每次翻译结果实时写入 JSON 缓存，应用重启后可一键恢复未完成的讲座笔记。
- **学术交互设计**：
    - **自动弹窗复盘**：讲座模式下点击停止，立即聚合所有分钟级小结弹出，消除等待焦虑。
    - 1/3 沉浸式分屏布局：上方看 Insight（逻辑摘要），下方看 Transcript（原文 + 翻译）。
    - 纯净中文翻译：过滤干扰，只留干货。
- **对比文章模板写作**：
    - 支持输入两个学术主体，自动生成纯相同点与纯不同点两篇完整的英文范文 + 中英对照词组笔记（朴素版/高级版），可选 Llama-3.3-70B / Qwen-32B / Qwen-72B 三种模型，支持自动重试与 PDF 导出。
- **暂停/继续**：
    - 录音过程中支持暂停与继续，无缝衔接。
- **开箱即用**：
    - 已预设 API 密钥，直接运行即可享受顶级算力。

## 🛠 开发环境要求

- **Flutter**: 3.24.0+
- **iOS**: 15.5+
- **Xcode**: 15.0+
- **依赖安装**:
  ```bash
  flutter pub get
  cd ios && pod install
  ```

## 🚀 快速启动

1. 连接 iPhone。
2. 运行 `flutter run --release`。
3. 确保 App 设置中的"蓝牙支持"已开启。
