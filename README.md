# Jeff Notes: 极致学术录音助手

Jeff Notes 是一款专为学术讲座、课堂记录设计的 iOS 实时转录与总结工具。它通过“跨云算力混编”技术，将全球最顶尖的 AI 模型整合进一个极简的 1/3 分屏界面中。

## ✨ 核心特色

- **跨云混编大脑**：
    - **Groq** 负责极速翻译，告别等待。
    - **DeepSeek V3** 负责全篇复盘，导师级水准。
    - **Qwen 2.5 72B** 负责实时提纲，精准捕捉考点。
- **硬件级音频增强**：
    - 针对 AirPods 深度优化，支持课堂远距离高清收音。
    - 16kHz PCM (WAV) 无损录音，识别率次元级提升。
- **学术交互设计**：
    - 1/3 沉浸式分屏布局：上方看逻辑，下方看原文。
    - 纯净中文翻译：过滤干扰，只留干货。
- **开箱即用**：
    - 已预设 API 密钥，直接运行即可享受顶级算力。

## 🛠 开发环境要求

- **Flutter**: 3.24.0+
- **iOS**: 15.5+
- **Xcode**: 15.0+
- **依赖安装**:
  ```bash
  flutter pub get
  cd ios && pod install
  ```

## 🚀 快速启动

1. 连接 iPhone。
2. 运行 `flutter run --release`。
3. 确保 App 设置中的“蓝牙支持”已开启。

## 📄 许可证

基于学术研究目的开发，禁止用于商业侵权录音。
